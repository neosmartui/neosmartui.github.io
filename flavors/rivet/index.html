Rivet Light

The industrial/mechanical NeoSmartUI flavor. This page uses the same shipping Core adapter CSS as Hardline and Soft; Rivet changes semantic Theme expression without changing component behavior.

Mechanical pressure, shared semantics

Rivet resolves 3px structural borders, 6px mechanical geometry, 5→3→0px crisp depth, 0→2→5px inward travel, paper surfaces, strong ink, lavender action color, and an explicit lavender focus ring.

Shared core.button

The same .ns-button adapter consumes Rivet tokens here. Hover/contact compresses inward by 2px; direct press seats the control by the full 5px.

Shared core.input

The editable field keeps native editing semantics and remains non-pressable while inheriting Rivet paper, ink, border, radius, and focus expression.

Shared core.card

Rivet depth is structural on informational surfaces. Static content remains stable through hover and pointer contact.

Stable mechanical surface

Crisp depth changes expression, not semantics.

The informational Card remains motionless because it is not a disguised control.

Shared core.badge

Rivet annotations stay compact and explicit; color supports written state meaning rather than replacing it.

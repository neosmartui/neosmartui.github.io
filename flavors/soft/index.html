Soft Light

The calm application-oriented NeoSmartUI flavor. This page uses the same shipping Core adapter CSS as Rivet and Hardline; only semantic Theme values change.

Compress, never float

Soft resolves visible 2px structure, moderate rounding, 3→1.5→0px structural depth, 0→1.5→3px contact travel, warm neutral surfaces, softened-blue action color, and explicit focus without changing component semantics.

Shared core.button

The same .ns-button adapter consumes Soft tokens here. Hover/contact compresses halfway; direct press fully seats the control.

Shared core.input

The editable field stays non-pressable while inheriting Soft's warm surface, moderate radius, visible boundary, and focus treatment.

Shared core.card

Static information stays stable even though Soft uses tactile depth for actual controls.

Mono Light

The editorial black/white/gray NeoSmartUI flavor. Mono uses the same shipping Core adapter CSS as Hardline, Soft, and Rivet; typography, keylines, grayscale contrast, and disciplined depth change expression without changing semantics.

Editorial pressure, shared semantics

Mono resolves 2px print-like keylines, square geometry, 3→1→0px crisp depth, 0→2→3px inward travel, serif-led hierarchy, grayscale-only semantic surfaces, and an independent black focus keyline.

Shared core.button

Shared core.input

Shared core.card
